# 🛒 Pokémon Center

A responsive, front-end e-commerce landing page built with pure HTML, CSS, and vanilla JavaScript — themed around the Pokémon Center concept. It includes a hero banner, product/category showcases, and a login page.

**🔗 Live Demo:** [pokemon-center-five.vercel.app](https://pokemon-center-five.vercel.app/)
**📦 Repository:** [github.com/IamSristi/Pokemon-Center](https://github.com/IamSristi/Pokemon-Center)

---

## 📖 About

Pokémon Center is a static e-commerce UI project that recreates a themed online store experience. It focuses on front-end design fundamentals — layout, responsiveness, and interactive UI elements — without a backend or database. It's a great reference for learning responsive e-commerce page structure.

---

## ✨ Features

- **Responsive Header & Navbar** — Collapsible mobile navigation with smooth slide-in animation
- **Hero Section** — Eye-catching banner with custom typography (Bangers / Carter One fonts)
- **Category Showcase** — Grid-based product category cards with hover effects
- **Special Offers Section** — Highlighted promotional cards
- **Product Listings** — Product cards with images, ratings, pricing, and quick-action buttons (cart/wishlist)
- **Services Section** — Icon-based service highlights (shipping, support, etc.)
- **Call-to-Action Banner** — Promotional section with background imagery
- **Brand Carousel** — Scrollable brand/partner logos
- **Footer** — Contact info, social links, and site navigation
- **Login Page** (`login.html`) — Dedicated user authentication UI
- **Back-to-Top Button** — Smooth scroll-to-top functionality
- **Fully Responsive Design** — Optimized across breakpoints (575px, 768px, 992px, 1200px)

---

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and markup |
| **CSS3** | Styling, custom properties (CSS variables), responsive layout with Flexbox/Grid |
| **JavaScript (Vanilla)** | UI interactivity (nav toggle, scroll behavior, etc.) |
| **[Ionicons](https://ionic.io/ionicons)** | Icon library |
| **Google Fonts** | Bangers, Carter One, Nunito Sans |
| **Vercel** | Deployment/hosting |

> This is a static front-end project — no backend, database, or package manager is required.

## 🚀 Getting Started

### Prerequisites
Just a modern web browser — no installation or build tools required.

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/IamSristi/Pokemon-Center.git
   ```
2. **Navigate into the project folder**
   ```bash
   cd Pokemon-Center
   ```
3. **Open in your browser**
   - Simply double-click `index.html`, or
   - Serve it locally (recommended) using a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code, or:
     ```bash
     npx serve .
     ```
